🔍 1. 总体概览：保存时发生了什么

当用户在PageOffice编辑完Excel后点击"保存"按钮，系统会依次执行以下5大操作：

①
PageOffice保存Excel文件
浏览器通过WebSave()将Excel文件内容提交到后端 /office/api/saveOriginalFile
②
Excel转图片 & PDF
后端将Excel的"结果页"转为多张PNG图片，将"数据页"转为PDF文件
③
更新数据库
将图片路径和PDF路径写入 ms_outer_task_allot 表的对应"证书"记录中
④
保存表单数据
将"记录模板页"中的委托信息、技术依据、计量标准、计量器具等保存到数据库
⑤
文件落盘
Excel原始文件保存到服务器磁盘指定目录
⚠️ 关键点：保存Excel时不会更新"记录"（JL）记录本身，而是更新对应的"证书"（ZS）记录。因为结果页图片和数据页PDF会在后续"证书编制"工序中用到。

@PostMapping("/saveOriginalFile")
public void saveOriginalFile(HttpServletRequest request, HttpServletResponse response,
                             String filePath, String type, Long allotId) throws IOException {
    response.setCharacterEncoding("utf-8");
    // 1. 参数校验
    if (StringUtils.isEmpty(filePath)) {
        throw new CustomException("文件路径不能为空", HttpStatus.SC_NOT_FOUND);
    }
    if (allotId == null) {
        throw new CustomException("任务明细ID不能为空!", HttpStatus.SC_NOT_FOUND);
    }
    // 2. 初始化PageOffice文件保存器（从请求中读取Excel内容）
    FileSaver fs = new FileSaver(request, response);
    // 3. 路径标准化
    String normalizedPath = FileUtils.normalizeOriginalFilePath(filePath);
    // 4. 判断是否为Excel文件，执行转换
    if (FileUtils.isExcelFile(normalizedPath)) {
        Map<String, Object> amap = excelToImgFile(normalizedPath);     // Excel→图片+PDF
        List<String> croppedResultImages = (List<String>) amap.get("croppedResultImages");
        String dataPdfPath = (String) amap.get("dataPdfPath");
        String resultImgJson = new ObjectMapper().writeValueAsString(croppedResultImages);
        // 5. 更新数据库（区分送检和现场）
        if (Constants.SET_STATUS_1.equals(type)) {  // type='1'=送检
            testTaskAllotService.updateTaskAllotWithResultTemplate(
                allotId, resultImgJson, null, dataPdfPath, filePath);
        } else {                                     // type='2'=现场
            msOuterTaskAllotService.updateTaskAllotWithResultTemplate(
                allotId, resultImgJson, null, dataPdfPath, filePath);
        }
    }
    // 6. 文件写入磁盘
    fs.saveToFile(normalizedPath);
    fs.close();
}
步骤操作说明
1参数校验校验 filePath 和 allotId 非空
2FileSaverPageOffice的 FileSaver 从HTTP请求中读取Excel二进制内容
3路径标准化FileUtils.normalizeOriginalFilePath() 将web路径转为本地绝对路径
4Excel→图片调用 excelToImgFile() 执行转换（详见第4节）
5更新数据库调用 Service 层的 updateTaskAllotWithResultTemplate()
6文件落盘fs.saveToFile() 将Excel写入服务器磁盘

excelToImgFile() 完整实现
private Map<String, Object> excelToImgFile(String filePath) {
    Map<String, Object> resultMap = new HashMap<>();
    File originalFile = new File(filePath);
    // 输出目录：和原文件同目录下的 result/ 子目录
    String parentDir = originalFile.getParent();
    String resultImgDir = parentDir + File.separator + "result";
    mkDir(resultImgDir);   // 创建 result/ 目录（例如 D:\uploadPath\original\xxx\result\）
    // 生成PDF文件名（在原Excel名基础上加后缀）
    String dataPdfPath = FilePathUtil.getPdfPath(filePath, "_data");     // 如 xxx_data.pdf
    String resultPdfPath = FilePathUtil.getPdfPath(filePath, "_result"); // 如 xxx_result.pdf
    try {
        // 步骤1：Excel "结果页" sheet → result.pdf
        ExcelSheetToPdfUtils.convertSingleSheet(filePath, resultPdfPath, "结果页");
        // 步骤2：Excel "数据页" sheet → data.pdf
        ExcelSheetToPdfUtils.convertSingleSheet(filePath, dataPdfPath, "数据页");
        // 步骤3：result.pdf 每一页 → PNG图片
        List<String> resultImages = PdfCertCleanConverter.convertPdfPages(resultPdfPath, 
                                                                           resultImgDir);
        // 返回结果
        resultMap.put("croppedResultImages", resultImages); // [".../result/page_0.png", ...]
        resultMap.put("dataPdfPath", dataPdfPath);          // ".../xxx_data.pdf"
    } catch (Exception e) {
        log.error("Excel转多图处理失败", e);
        throw new CustomException("Excel转图片处理失败", e);
    }
    return resultMap;
}

4.3 使用的工具类

工具类方法作用
ExcelSheetToPdfUtils convertSingleSheet(filePath, pdfPath, sheetName) 使用Aspose.Cells库，将Excel的指定Sheet转换为PDF文件
PdfCertCleanConverter convertPdfPages(pdfPath, outputDir) 使用PDFBox，将PDF的每一页渲染为高分辨率PNG图片

@Override
public void updateTaskAllotWithResultTemplate(Long allotId, String resultImgJson, 
        String dataImgPath, String dataPdfPath, String normalizedPath) {
    try {
        // 1. 根据 allotId 查询当前"记录"任务
        TestTaskAllot taskAllot = testTaskAllotMapper.selectTestTaskAllotByAllotId(allotId);
        // 2. 根据 taskId 找到对应的"证书"（ZS）记录
        TestTaskAllot taskCaretInfo = getTestTaskAllot(
            taskAllot.getTaskId(), Constants.TEMPLATE_CLASSIFY_ZS);  // ZS = 证书
        if (ObjectUtils.isEmpty(taskCaretInfo)) {
            log.info("未找到对应的任务证书记录，allotId: {}", allotId);

        }
        // 3. 路径转换：本地绝对路径 → Web访问路径
        String dataPath = PathConverter.convertToOriginalWebPath(dataPdfPath);
        // 4. 多图片路径整体转换

        String dataFileUrl  = convertPathsToWebJson(dataImgPath);    // 数据页图片路径(Json)

        taskCaretInfo.setResultFileUrl(resultFileUrl);    // 结果页图片文件
        taskCaretInfo.setDataFileUrl(dataFileUrl);        // 数据页图片文件
        taskCaretInfo.setDataPdfUrl(dataPath);            // 数据页PDF文件
        taskCaretInfo.setOriginalExcelFileUrl(normalizedPath); // Excel原始文件
        // 6. 执行数据库更新
        testTaskAllotMapper.updateTestTaskAllot(taskCaretInfo);
    } catch (Exception e) {
        log.error("更新任务分配记录失败，taskId: {}", allotId, e);
    }

5.3 路径转换工具方法

📄 TestTaskAllotServiceImpl.java / MsOuterTaskAllotServiceImpl.java — convertPathsToWebJson()

convertPathsToWebJson — 批量路径转换
private String convertPathsToWebJson(String json) throws Exception {
    if (ObjectUtils.isEmpty(json)) {
        return null;
    }
    // 1. 解析JSON数组（例如：["D:\\uploadPath\\xxx\\page_0.png", ...]）
    ObjectMapper objectMapper = new ObjectMapper();
    var list = objectMapper.readValue(json, List.class);
    // 2. 将每个本地路径转为Web路径（例如："/profile/original/xxx/page_0.png"）
    var webList = list.stream()
        .map(path -> PathConverter.convertToOriginalWebPath(path.toString()))
        .toList();
    // 3. 重新序列化为JSON存储
    return objectMapper.writeValueAsString(webList);
}

7.2 recordEditExcel — 打开Excel时的预配置

📄 OfficeOnlineApi.java — 第437~489行

在打开Excel进行编辑前，会读取模板子表的 reg_content 字段（区域配置），设置对应的只读区域。模板中配置的只读区域（如委托单位名称区域），用户在Excel中不可编辑，只有"数据区域"可以编辑。

recordEditExcel — 打开时的关键配置
@GetMapping("/recordEditExcel")
public Map<Object, Object> recordEditExcel(HttpServletRequest request, 
        String filePath, Long templateChildId) {
    // 1. 查询模板子配置
    MsTemplateChild templateChild = msTemplateChildService.selectMsTemplateChildByTemplateChildId(templateChildId);
    // 2. 解析可编辑区域配置(reg_content字段)
    List<RegionalDto> convertedList = JSON.parseObject(templateChild.getRegContent(), ...);
    // 3. 设置Excel的只读/可编辑区域
    WorkbookWriter wb = new WorkbookWriter();
    convertedList.forEach(reg -> {
        SheetWriter sheet = wb.openSheet(reg.getSheetName());
        List<String> valueList = Arrays.asList(reg.getRegionalValues().split(","));
        valueList.forEach(value -> {
            ExcelTableWriter tableA = sheet.openTable(value);
            tableA.setReadOnly(false);  // 标记为"可编辑"，其余区域只读
        });
    });
    // 4. 打开Excel（提交模式）
    poCtrl.setWriter(wb);
    openSubmitExcelument(poCtrl, normalizedPath, currentUser.getNickName());
    // OpenModeType.xlsSubmitForm → Excel以"提交表单"模式打开，支持保存回调
}

前端传入：filePath（Excel模板路径）、allotId（任务ID）、type（"1"送检/"2"现场）

存入数据库：证书（ZS）记录的 result_file_url（图片JSON数组）、data_pdf_url（PDF路径）、original_excel_file_url（Excel路径）
