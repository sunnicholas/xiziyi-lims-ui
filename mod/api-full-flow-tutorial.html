1. 需求分析：我们要做什么

假设产品经理提了一个需求：

📋 需求描述：需要一个"演示数据管理"功能，支持查询演示数据列表，可按名称和内容模糊搜索，后续还要支持增删改。

需求拆解为技术任务

技术任务对应文件说明
建表SQL脚本sys_demo 表，含 id、demo_name、demo_content 等字段

Service接口SysDemoService.java定义业务方法签名
Service实现SysDemoServiceImpl.java实现业务逻辑
ControllerSysDemoController.java暴露 HTTP 接口

2. 项目架构总览：代码放在哪

本项目基于 若依（RuoYi） 框架，采用 Maven 多模块架构，Spring Boot 2.5 + MyBatis-Plus。

xiziyi-lims-service/ ├── xzy-common/ ← 通用工具模块（BaseEntity、AjaxResult、工具类等） ├── xzy-framework/ ← 框架核心（安全、拦截器、数据源等） ├── xzy-system/ ← 系统模块（部门、用户、角色、SysDemo在这里） │ └── src/main/ │ ├── java/com/xzy/system/ │ │ ├── domain/ ← 实体类（SysDemo.java、DemoQuery.java） │ │ ├── mapper/ ← Mapper接口（SysDemoMapper.java） │ │ └── service/ │ │ ├── SysDemoService.java ← Service接口 │ │ └── impl/ │ │ └── SysDemoServiceImpl.java ← Service实现 │ └── resources/mapper/system/ │ └── SysDemoMapper.xml ← SQL映射文件 ├── xzy-admin/ ← 启动模块 + Controller层 │ └── src/main/ │ ├── java/com/xzy/web/controller/system/ │ │ └── SysDemoController.java ← Controller在这里 │ └── resources/ │ ├── application.yml ← 主配置文件 │ └── application-druid.yml ← 数据源配置 ├── xzy-measure/ ← 计量模块 ├── xzy-quality/ ← 质量模块 ├── xzy-crm/ ← 客户关系模块 └── pom.xml ← 父POM，管理所有模块
⚠️ 关键理解：Controller 放在 xzy-admin 模块，而 Domain/Mapper/Service 放在 xzy-system 模块。这是因为 xzy-admin 依赖 xzy-system，xzy-system 依赖 xzy-common。模块间依赖关系：xzy-admin → xzy-system → xzy-common

5. Step 3 - Query 查询参数类（DTO）

3
创建 Query 查询参数类
DTO

完整代码
package com.xzy.system.domain; import io.swagger.annotations.ApiModelProperty; import lombok.Data; @Data public class DemoQuery { /** 演示名称（模糊查询） */ @ApiModelProperty("演示名称") private String demoName; /** 演示内容（模糊查询） */ @ApiModelProperty("演示内容") private String demoContent; }
💡 为什么需要单独的 Query 类？
查询参数和实体类职责不同：实体类映射完整的数据表（含 id、时间等），而 Query 类只接收前端传入的搜索条件。这样接口更清晰，也不会暴露不必要的字段。

命名规则：业务名 + Query。如 DemoQuery、EntrustDto、TaskDto。本项目 Query 和 DTO 都放在 domain 包下。

6. Step 4 - Mapper 接口（数据访问层）

4
创建 Mapper 接口
Mapper
文件位置
xzy-system/src/main/java/com/xzy/system/mapper/SysDemoMapper.java
完整代码
package com.xzy.system.mapper; import com.xzy.system.domain.DemoQuery; import com.xzy.system.domain.SysDemo; import org.apache.ibatis.annotations.Mapper; import java.util.List; /** * 演示表 数据映射层 */ @Mapper public interface SysDemoMapper { /** * 查询所有演示数据 * @param query 查询条件 * @return 数据列表 */ List<SysDemo> selectSysDemoList(DemoQuery query); }

Mapper 接口要点

要点说明
@Mapper 注解告诉 MyBatis 这是一个映射接口，Spring 会自动生成实现类（代理对象）
方法名 = 操作 + 实体名如 selectSysDemoList、insertSysDemo、updateSysDemo、deleteSysDemoById
方法名对应 XML 的 id方法名必须和 XML 中 <select id="selectSysDemoList"> 的 id 一致
参数类型查询用 Query/DTO，增删改用实体类，单参数用 Long/String
返回类型列表用 List<SysDemo>，单条用 SysDemo，增删改用 int

<?xml version="1.0" encoding="UTF-8" ?> <!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "http://mybatis.org/dtd/mybatis-3-mapper.dtd"> <!-- namespace = Mapper接口的全限定类名，必须一致！ --> <mapper namespace="com.xzy.system.mapper.SysDemoMapper"> <!-- 结果映射：数据库列名 → Java属性名（驼峰自动转换也可，但显式映射更清晰） --> <resultMap type="SysDemo" id="SysDemoResult"> <id property="id" column="id"/> <result property="demoName" column="demo_name"/> <result property="demoContent" column="demo_content"/> </resultMap> <!-- 查询列表：id 必须和 Mapper 接口方法名一致 --> <select id="selectSysDemoList" resultMap="SysDemoResult"> select id, demo_name, demo_content, create_time, remark from sys_demo <where> <!-- 动态SQL：只有参数不为空时才拼接条件 --> <if test="demoName != null and demoName != ''"> and demo_name like concat('%', #{demoName}, '%') </if> <if test="demoContent != null and demoContent != ''"> and demo_content like concat('%', #{demoContent}, '%') </if> </where> order by id desc </select> <!-- 根据ID查询 --> <select id="selectSysDemoById" resultMap="SysDemoResult"> select id, demo_name, demo_content, create_time, remark from sys_demo where id = #{id} </select> <!-- 新增：useGeneratedKeys 回填自增主键 --> <insert id="insertSysDemo" parameterType="SysDemo" useGeneratedKeys="true" keyProperty="id"> insert into sys_demo <trim prefix="(" suffix=")" suffixOverrides=","> <if test="demoName != null and demoName != ''">demo_name,</if> <if test="demoContent != null and demoContent != ''">demo_content,</if> <if test="remark != null">remark,</if> create_time </trim> <trim prefix="values (" suffix=")" suffixOverrides=","> <if test="demoName != null and demoName != ''">#{demoName},</if> <if test="demoContent != null and demoContent != ''">#{demoContent},</if> <if test="remark != null">#{remark},</if> sysdate() </trim> </insert> <!-- 修改 --> <update id="updateSysDemo" parameterType="SysDemo"> update sys_demo <set> <if test="demoName != null and demoName != ''">demo_name = #{demoName},</if> <if test="demoContent != null and demoContent != ''">demo_content = #{demoContent},</if> <if test="remark != null">remark = #{remark},</if> update_time = sysdate() </set> where id = #{id} </update> <!-- 删除 --> <delete id="deleteSysDemoById" parameterType="Long"> delete from sys_demo where id = #{id} </delete> </mapper>

XML 关键标签速查

标签作用关键属性
<mapper namespace="...">绑定 Mapper 接口namespace = 接口全限定名
<resultMap>列名 → 属性名映射type=实体别名, id=映射标识
<select>查询id=方法名, resultMap/resultType
<insert>新增useGeneratedKeys=true 回填主键
<update>修改parameterType=参数类型
<delete>删除parameterType=参数类型
<where>智能 WHERE 子句自动去除开头的 AND/OR
<if test="...">动态条件满足条件才拼接 SQL
<set>智能 SET 子句自动去除末尾逗号
<trim>自定义前后缀prefix, suffix, suffixOverrides
<foreach>批量遍历collection, item, separator
#{xxx}参数占位符预编译，防 SQL 注入
${xxx}字符串替换直接拼接，有注入风险，慎用
⚠️ XML 文件位置规则：
源码位置：xzy-system/src/main/resources/mapper/system/SysDemoMapper.xml
编译后位置：xzy-system/target/classes/mapper/system/SysDemoMapper.xml（Maven 自动复制，内容一致）
MyBatis 扫描路径配置在 application.yml：mybatis-plus.mapper-locations: classpath*:mapper/**/*Mapper.xml

8.2 Service 实现类

完整代码
package com.xzy.system.service.impl; import com.xzy.system.domain.DemoQuery; import com.xzy.system.domain.SysDemo; import com.xzy.system.mapper.SysDemoMapper; import com.xzy.system.service.SysDemoService; import org.springframework.beans.factory.annotation.Autowired; import org.springframework.stereotype.Service; import java.util.List; @Service public class SysDemoServiceImpl implements SysDemoService { @Autowired private SysDemoMapper sysDemoMapper; // 注入 Mapper @Override public List<SysDemo> selectSysDemoList(DemoQuery query) { return sysDemoMapper.selectSysDemoList(query); // 直接委托给 Mapper } }

Service 层要点

要点说明
接口和实现分离接口定义方法签名，实现类写业务逻辑。Controller 注入接口而非实现类（面向接口编程）
@Service标记为 Spring Bean，自动注册到容器
@Autowired自动注入依赖（Mapper、其他 Service）
实现类包名接口在 service/，实现类在 service/impl/
命名规则接口：I前缀或直接业务名（本项目两种都有）；实现类：接口名 + Impl
💡 本项目命名风格：系统模块 Service 接口不加 I 前缀（如 SysDemoService），但部分模块加 I 前缀（如 ISysDeptService）。新代码建议统一加 I 前缀以区分接口和实现类。

方法场景返回示例

⚠️ 注意：部分字段标记了 @TableField(exist = false)，意味着 MyBatis-Plus 不会将它们映射到数据库列。但在 MyBatis XML 中手动写 SQL 时，这些字段仍可在 resultMap 中映射（只要 SQL 查出来了对应列）。
