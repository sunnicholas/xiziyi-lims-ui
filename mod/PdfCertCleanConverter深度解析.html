3.3 ExcelSheetToPdfUtils 的关键处理

在把 Excel 交给 PdfCertCleanConverter 之前，ExcelSheetToPdfUtils 做了以下预处理：

步骤做了什么为什么
1. 复制文件copyFile(originalFile, tempFile) 创建临时副本不破坏原始文件
2. 公式处理遍历所有单元格，把公式转为计算结果值（如SUM转数值）转PDF时公式计算结果会丢失
3. 错误值处理把 #VALUE!、#NAME? 等错误值替换为空字符串防止PDF中出现乱码
4. 删除无关Sheet只保留目标Sheet（"结果页"或"数据页"），删除其他PDF只包含需要的那个Sheet
5. LibreOffice转换converter.convert(tempFile).to(new File(pdfPath)).execute()实际生成PDF文件

4.2 convertPdfPages() —— 核心方法

📌 方法签名
public static List<String> convertPdfPages(String pdfPath, String outputDir)

执行步骤：

1
PDDocument.load 加载PDF
使用 try-with-resources 自动管理资源。PDFBox读取PDF文件的所有页面结构。
2
创建 PDFRenderer + 确保输出目录存在
PDFRenderer 负责把PDF页面渲染成Java BufferedImage。同时检查 outputDir 是否存在，不存在则 mkdirs()。
3
renderImageWithDPI(pageIndex, 600) 渲染当前页
最关键的一步！600DPI渲染：A4纸(210×297mm)≈4961×7016像素。这保证了后续打印/放大查看都不会模糊。
4
smartCrop() 智能裁剪
扫描左/右/下三个方向的白边，裁掉无用空白。顶部不裁（表格类PDF顶部开始就是内容）。
5
ImageIO.write 输出PNG文件
文件命名 page_1.png, page_2.png... 保存到 resultImgDir 目录中。PNG无损压缩，保留600DPI的所有清晰度。

4.3 智能裁剪算法详解

不裁上方的原因：检验表格的顶部就是表头（如"检测结果"、"标准信息"等），从Y=0开始就有内容，不需要裁。

// smartCrop 裁剪逻辑示意
// 原始图片 7000px高，内容只占中间4000px

// ← 左白边(200px被裁) →|=====表格内容=====|← 右白边(150px被裁) →
// 顶部从0开始就是内容（不裁）
// =====表格内容=====
// ↓ 底部白边(2500px被裁) ↓

// 最终保留: X=left-20, Y=0, W=right-left+40, H=bottom+20

为什么 WHITE_THRESHOLD = 254 而不是 255？

PDF渲染时可能产生细微色差，某些"看起来纯白"的像素实际RGB值是(254,254,254)。如果阈值设为255，这些像素会被误判为"有内容"，导致白色背景区域没有被裁剪掉。254的容忍度确保只有明确有颜色内容的像素才算"有内容"。

7.3 关键问题解答

❓ 为什么数据页PDF不转PNG？
"数据页"PDF 是留给出证书阶段使用的——在出证书时会把多个PDF合并成一个完整的证书PDF文件。所以数据页保留PDF格式比PNG更合适（PDF可以无损拼接，PNG拼接会损失矢量信息）。
❓ 为什么 result/ 目录和PDF放在同一父目录下？
这样做方便管理和清理：一个任务的所有文件（Excel + 两个PDF + result目录中的PNG）都在同一个日期目录下，删除一个任务时不需要去多个地方找文件。

项目中存在两个功能相似但实现不同的类：

对比维度PdfCertCleanConverter 👈本文PdfCertCleanConverters (变体)
输出格式PNG（位图）SVG（矢量图）

裁剪方式像素扫描 + BufferedImage.getSubimage像素扫描 + SVG viewBox裁剪
文件大小较大（600DPI位图约5-20MB）较小（矢量XML约50-500KB）
缩放效果放大有限制（像素限制）无限缩放不模糊（矢量特性）
浏览器兼容所有浏览器都支持PNG所有现代浏览器支持SVG
是否被调用✅ 被 OfficeOnlineApi 调用❌ 当前未在项目中使用
适用场景打印、存档、展示网页嵌入、在线预览、无限缩放查看
💡 为什么用PNG而不是SVG？
PNG是"所见即所得"——在任何设备、任何软件中打开都一样。SVG在不同浏览器/软件中渲染效果可能不一致（字体、表格线可能有差异），对于需要严格一致的检验记录来说，PNG更可靠。而且PNG可以直接用于打印和归档。

  • ✅ 裁剪是视觉优化—— 去白边让图片"内容撑满"，在证书排版时更好看、更省空间
