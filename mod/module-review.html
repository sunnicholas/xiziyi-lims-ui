✅ 审核管理

贯穿全流程：委托审核 → 记录审核 → 证书审核 → 归档确认

1. 审核类型总览

审核类型审核对象审核人Controller/接口
委托审核 ms_entrust_task 业务部部长/审核员 MsEntrustTaskController
POST /measure/msEntrustTask/audit
记录审核 test_task_allot (记录) 检测部部长/科室主任 TestTaskAllotController
GET /measure/testTaskAllot/auditSubmit
证书审核 test_task_allot (证书) 审核员 TestTaskAllotController
GET /measure/testTaskAllot/certSubmit → 审核
模板审核 ms_template_info 技术负责人 MsTemplateInfoController
POST /measure/msTemplateInfo/audit
子模板审核 ms_template_child 技术负责人 MsTemplateChildController
POST /measure/msTemplateChild/audit

2. 编制审核管理

API：xiziyi-lims-web/src/api/ReviewManagement/ReviewManagement.js

前端页面：views/ReviewManagement/ApprovalManage/index.vue（审批管理）

GET/measure/testTaskAllot/auditList编制审核列表
GET/measure/testTaskAllot/handList经办任务列表
GET/measure/testTaskAllot/auditSubmit证书审核提交
GET/measure/testTaskAllot/recordList操作历史

3. 审核数据表

表名审核相关字段说明
ms_entrust_taskaudit_status, audit_user_id, audit_time, audit_remark委托审核信息
test_task_allotrecord_status(记录状态), cert_status(证书状态), audit_status(审核状态)编制审核信息
ms_entrust_recordstatus, record_content, create_time, create_by所有操作记录

审核提交 SQL 示例

-- auditSubmit: 证书审核提交 UPDATE test_task_allot SET cert_status = #{certStatus}, audit_status = #{auditStatus}, audit_user_id = #{auditUserId}, audit_time = sysdate(), audit_remark = #{auditRemark} WHERE allot_id = #{allotId}
⚠️ 审核注意事项：审核涉及到状态流转，需要保持状态一致性。使用了 @Transactional 事务注解确保审核操作和执行记录INSERT在一个事务中。
