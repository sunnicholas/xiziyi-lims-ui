1. 文件存储根目录

📌 根目录配置：application.yml → xzy.profile = /Users/sunnicholas/lims/uploadPath
所有业务文件都在此目录下按规则生成子目录。

1.1 完整目录结构

{profile}/ ← 根目录 (/Users/sunnicholas/lims/uploadPath) ├── upload/ ← 通用上传文件 (common/upload) │ └── {yyyyMMdd}/ ← 按日期分目录 │ └── {uuid}.ext ← UUID命名避免冲突 │ ├── entrust/ ← 委托单文件 │ └── {date}/{entrustId}/ │ └── 委托单.docx │ ├── cert/ ← 证书文件 │ └── {date}/{entrustId}/{allotId}/ │ ├── 证书.docx ← Word编辑文件 │ ├── 证书.pdf ← 最终PDF │ └── img/ ← 证书中合成的图片 │ ├── record/ ← 记录文件 │ └── {date}/{entrustId}/{allotId}/ │ └── 原始记录.xlsx │ ├── template/ ← 模板文件 │ └── {classify_id}/{template_id}/ │ ├── 证书模板.docx │ └── child/{child_id}/ │ └── 记录模板.xlsx │ └── sign/ ← 签名图片 └── {userId}.png

2.2 上传代码逻辑

// 文件上传处理流程 (FileUploadController / FileUtils) 1. 接收 UploadedFile (Spring MultipartFileResolver) 2. 获取原始文件名 → UUID新文件名(保留扩展名) 3. 拼接日期路径: profile + "/upload/" + yyyyMMdd + "/" 4. 创建目录: file.mkdirs() 5. 写入文件: file.transferTo(targetFile) 6. 返回: fileName(原始名), url(相对路径 "upload/20260429/uuid.docx") 7. 前端拿到 url 存储到对应业务表的字段中

6. 常见文件操作问题排查

⚠️ 问题1：Aspose 生成的文件有水印
原因：license.xml 未加锁或不正确
排查：检查 xzy-admin/src/main/resources/license.xml 是否存在且内容正确
加载位置：LimsApplication.java 启动时通过 @PostConstruct 加载 ⚠️ 问题2：PageOffice 打不开文件
原因：模板文件路径不存在，或 JDK 版本不兼容
排查：检查 template_path 字段存储的路径是否正确，确认文件存在于磁盘
检查 JDK 版本（PageOffice 通常在 JDK 8u202 以下较稳定） ⚠️ 问题3：Windows/Linux 路径分隔符问题
解决：使用 FilePathUtil.java 或 PathConverter.java 统一处理
不要手动拼 "/" 或 "\"，使用 File.separator 或工具类 ⚠️ 问题4：上传文件找不到
确认数据库存储的是相对路径还是绝对路径
确认 xzy.profile 配置的目录磁盘空间充足
确认文件权限（Linux 上需要写权限）
