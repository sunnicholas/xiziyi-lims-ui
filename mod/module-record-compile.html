📄 记录编制

上一环节：任务分配 → 记录编制（填写实验数据）→ 下一环节：审核（可选）→ 证书编制

1. 模块概述

检测员完成实验后，在系统中编写原始记录。系统根据模板（子模板）生成 Excel 记录表，检测员填写实验数据，提交后进入审核环节。

这是 LIMS 系统的核心环节之一，涉及 PageOffice 在线编辑、Excel 模板填充、文件生成与存储。

📌 前端页面：xiziyi-lims-web/src/views/establishment/msRecordEstablish/index.vue
📌 在线编辑组件：xiziyi-lims-web/src/components/pageoffice/JLadd.vue、JLupdate.vue
📌 权限标识前缀：measure:testTaskAllot

2. 前端调用的接口

API 封装：xiziyi-lims-web/src/api/establishment/EquipmentForInspection.js
模板中的部分接口在 msTemplateInfo.js 中

GET/measure/testTaskAllot/list记录编制列表
GET/measure/testTaskAllot/{allotId}编制详情回显
GET/measure/testTaskAllot/getRecordEcho核心：记录编制回显(根据模板ID查询Excel回显数据)
POST/measure/testTaskAllot新增记录编制
PUT/measure/testTaskAllot修改记录编制
GET/measure/testTaskAllot/submit记录编制提交
GET/measure/testTaskAllot/createOriginalFile核心：上传记录文件路径/生成原始记录文件
GET/office/api/excelPageOffice 在线Excel编辑
GET/office/api/excelViewExcel查看模式

3. 后端实现

3.1 Controller: TestTaskAllotController

文件：xzy-admin/src/main/java/com/xzy/web/controller/measure/TestTaskAllotController.java

@RequestMapping：/measure/testTaskAllot

这是整个系统最核心、代码量最大的 Controller，处理记录编制和证书编制。

3.2 核心方法详解

方法路径传参说明
list() GET /list TestTaskAllot 查询编制管理列表（记录编制列表）
getRecordEcho() GET /getRecordEcho allotId(分配ID),
templateChildId(子模板ID)		 记录编制回显。根据分配ID查询委托信息+样品信息+检测项目；根据子模板ID查询Excel模板，填充数据后打开 PageOffice 在线编辑
JLsubmit() GET /submit allotId 记录编制提交，状态变更为待审核
createOriginalFile() GET /createOriginalFile allotId,
filePath(记录文件路径)		 原始记录文件提交。保存用户编辑完的记录文件路径到数据库

4. 记录编制回显流程详解

这是最核心的流程，展示了 L240-L310 的 getRecordEcho() 方法完整逻辑：

// TestTaskAllotController.getRecordEcho(allotId, templateChildId) Step 1: 查询分配信息 SELECT * FROM test_task_allot WHERE allot_id = #{allotId} Step 2: 根据分配信息查询委托单 SELECT * FROM ms_entrust_task WHERE id = #{entrustId} Step 3: 查询样品信息和检测项目信息 SELECT * FROM ms_sample_info WHERE entrust_id = #{entrustId} SELECT * FROM bas_meterage_item WHERE id IN (检测项目ID列表) Step 4: 查询子模板信息 SELECT * FROM ms_template_child WHERE id = #{templateChildId} → 获取 Excel 模板文件路径 (template_path) Step 5: 打开 PageOffice 在线编辑 返回模板文件路径 + 委托数据 + 样品数据 → 前端 PageOffice 组件加载 Excel 模板 → 将数据填充到 Excel 的指定单元格/书签区域 → 检测员在浏览器中编辑，编辑完后保存

5. 文件存储路径

📁 记录文件存储规则：
模板文件：通常在 {profile}/template/ 目录下
用户编辑后的记录文件：{profile}/record/{entrustId}/{allotId}/原始记录.xlsx

文件操作方式：
1. PageOffice 在线编辑 → 点保存 → 自动保存到指定路径
2. createOriginalFile 接口 → 手动指定文件路径 → 更新数据库
