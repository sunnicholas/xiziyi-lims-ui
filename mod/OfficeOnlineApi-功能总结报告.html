📋 核心概述

OfficeOnlineApi 是一个基于 PageOffice 6.5.1.2 组件的在线 Office 文档编辑控制器， 提供 Word、Excel 文档的在线编辑、预览、保存，以及 PDF 在线预览，并深度集成了 LIMS（实验室信息管理系统）的业务流程。

Word 在线编辑 Excel 在线编辑 PDF 预览 LIMS 证书回显 Excel→图片/PDF 转换 防伪码二维码 电子签名 送检+现场双模式

🔌 API 端点清单（13个）

🗂 文件保存类

POST /office/api/saveFile
通用保存文件——根据文件后缀分 Word/Excel 路径归一化后保存
参数: filePath (String, 必填) — 模板物理路径
POST /office/api/saveZsFile
证书保存接口（送检任务）——通过 allotId 反查任务分配记录获取文件路径后保存
参数: allotId (Long) — 送检任务明细ID
POST /office/api/saveXcZsFile
证书保存接口（现场任务）——通过 allotId 反查现场任务分配记录获取文件路径后保存
参数: allotId (Long) — 现场任务明细ID
POST /office/api/saveOriginalFile
保存原始记录文件——若为 Excel 文件会触发 "结果页/数据页" 分离转图片+PDF 流程，并更新任务记录的 resultTemplate 字段
参数: filePath (String), type (String: 送检/现场), allotId (Long)
POST /office/api/saveData
提取 Word 模板中的 DataRegion 与 Table 元信息——遍历所有数据区域，识别 table_ 前缀区域并记录行列数，存入 Redis 缓存

📊 Excel 编辑/预览类

GET /office/api/excel
在线 Excel 普通编辑——以当前用户身份打开 Excel 进行编辑，PageOffice Ctrl 含自定义保存按钮
参数: filePath (String, 必填)
GET /office/api/recordEditExcel
记录编制在线 Excel——根据 templateChildId 加载区域配置（RegContent），设置指定 Sheet/Table 为可写区域，以表单提交模式打开
参数: filePath (String), templateChildId (Long, 必填)
GET /office/api/excelView
在线 Excel 预览——以只读模式打开 Excel
参数: filePath (String, 必填)

📝 Word 编辑/预览类

GET /office/api/word
在线 Word 编辑——路径安全校验后以普通编辑模式打开
参数: filePath (String, 必填)
GET /office/api/viewWord
在线 Word 预览——以只读模式打开
参数: filePath (String, 必填)
GET /office/api/openWordTag
打开 Word 并定义书签（数据区域）——从字典表加载书签列表批量 defineDataRegion，返回书签表格元信息（来自 Redis）
参数: filePath (String, 必填)
GET /office/api/openWordEchoTag
核心流程：送检任务数据回显书签——填充委托信息、日期、签名、结果页图片、防伪码、计量标准/器具表格等，支持只读/编辑模式
参数: allotId (Long), readOnly (String: Y/N)
GET /office/api/openWordEchoXcTag
核心流程：现场任务数据回显书签——与送检流程逻辑一致，但数据源来自现场任务表 MsOuterTaskAllot
参数: allotId (Long), readOnly (String: Y/N)

🔄 核心业务流程

流程一：证书编制与数据回显（送检 / 现场）

1
前端调用 /openWordEchoTag (送检) 或 /openWordEchoXcTag (现场)
2
通过 allotId 反查任务分配信息 getTaskAllot() / getOuterTaskAllot()
3
获取证书编号 getTaskCertNumber()，准备文档数据 prepareDocumentData()
4
填充书签映射 createBookmarkDataMap()：委托编号、样品名称、规格、日期、签名图片、防伪码二维码、结果页图片
5
填充数据标签 createDataTagDataMap()：证书编号、委托名称
6
若状态=30（编制完成），回显计量标准表格 setStandardInfoTagValues() + 计量器具表格 setDeviceInfoTagValues()
7
PageOffice 打开 Word 文档（只读/编辑模式），用户在线编辑
8
保存时触发 /saveZsFile (送检) 或 /saveXcZsFile (现场)

流程二：原始记录 Excel 分离转图片

1
前端保存原始记录，调用 /saveOriginalFile
2
若为 Excel → excelToImgFile()
3
分离"结果页"Sheet → PDF → 图片（png）
4
分离"数据页"Sheet → PDF
5
结果页图片 JSON 存入 resultTemplate 字段（送检/现场分别更新）

🛡 安全机制

  • 路径越权防护：isValidFilePath() 使用 getCanonicalPath() 校验文件必须在 XiziYiConfig.getUploadPath() 目录内
  • 用户认证校验：每个端点都校验 SecurityUtils.getLoginUser() 是否存在，未登录抛出 UNAUTHORIZED 异常
  • 参数非空校验：所有端点对 filePath/allotId 等关键参数做空值检查
  • 文件存在校验：结果页图片插入前会检查文件是否存在，不存在抛出异常
  • PDF 防拷贝：showPdf 支持 allowCopy 参数控制拷贝/下载权限
  • 平台兼容：Windows/Linux 文件路径协议自动适配 (file:// 前缀)
