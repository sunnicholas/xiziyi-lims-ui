🖨️ 证书与标签打印

上一环节：证书编制审核通过 → 打印证书/合格证标签 → 发放

1. 证书打印

审核通过的证书进入打印列表，支持批量打印和打印状态回写。

API：xiziyi-lims-web/src/api/print/printingcertificate.js

GET/measure/testTaskAllotPrint/list证书打印列表
GET/measure/testTaskAllotPrint/updatePrintStatus更新打印状态

Controller：TestTaskAllotPrintController.java
@RequestMapping：/measure/testTaskAllotPrint

证书文件获取流程

1. 查询已审核通过的证书 SELECT * FROM test_task_allot WHERE cert_status >= 审核通过状态 2. 获取证书PDF文件路径 {profile}/cert/{entrustId}/{allotId}/证书.pdf 3. 前端调取PDF进行打印 4. 打印成功 → updatePrintStatus 更新打印记录

2. 合格证标签打印

合格证是一种简化的标签式证书，通常粘贴在仪器设备上。支持批量标签打印、防伪码打印。

API：xiziyi-lims-web/src/api/print/labelprinting.js

GET/measure/labelPrinting/list标签打印列表
GET/measure/labelPrinting/{id}标签详情
POST/measure/labelPrinting新增标签
POST/measure/labelPrinting/batchGenerate批量生成标签

前端页面：views/print/labelprinting/index.vue
打印组件：components/Printablelabel/index.vue
