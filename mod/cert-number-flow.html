🔧 核心方法详解 - incrZsNumberStr

文件位置：xzy-common/src/main/java/com/xzy/common/service/impl/ConfigServiceImpl.java:158-200
功能说明：生成带年月前缀的递增流水号，确保每月重置，使用Redis原子操作保证并发安全

方法签名

private String incrZsNumberStr(String pre, String entrustTime, int length, String redisKey)

参数说明

参数 类型 说明
pre String 编号前缀（如 LXSEJJG）
entrustTime String 委托时间（格式：yyMM，如 2604）
length int 流水号位数（如5表示00001格式）
redisKey String Redis基础键（如 MEASURE）

核心处理流程

  1. 参数校验：检查前缀和Redis键不为空，位数在1-10之间
  2. 生成Redis键：格式为 `{redisKey}:{pre}:incr:{entrustTime}`，确保每月独立计数
  3. 原子递增：使用Redis INCR命令保证并发安全，自动创建不存在的键
  4. 容错处理：如果是新创建的键且不是当月第一天，强制重置为1
  5. 设置过期：键的过期时间设为40天，确保覆盖整月并留缓冲
  6. 格式化输出：流水号补0到指定位数，拼接前缀+年月+流水号

核心代码实现

// 生成带年月的唯一键（确保每月重置）
String monthlyKey = String.format("%s:%s:incr:%s", redisKey, pre, entrustTime);

// Redis原子递增操作
Long sequence = redisTemplate.execute((RedisCallback<Long>) connection -> {
byte[] keyBytes = redisTemplate.getStringSerializer().serialize(monthlyKey);
Boolean exists = connection.exists(keyBytes);
Long seqValue = connection.incr(keyBytes);
// 容错处理：新键且不是1号则强制重置
if (seqValue == 1 && (exists == null || !exists)) {
int dayOfMonth = LocalDate.now().getDayOfMonth();
if (dayOfMonth != 1) {
connection.del(keyBytes);
seqValue = connection.incr(keyBytes);
}
}
// 设置40天过期时间
connection.expire(keyBytes, TimeUnit.DAYS.toSeconds(40));
return seqValue;
});

// 格式化为指定位数
String sequenceStr = String.format("%0" + length + "d", sequence);
return pre + entrustTime + sequenceStr;

设计亮点

  • 并发安全：使用Redis INCR原子操作，避免并发冲突
  • 月度重置：根据entrustTime（年月）生成独立的Redis键，自动实现每月流水号从1开始
  • 容错机制：检测异常情况（非月初但键不存在），自动修复
  • 资源清理：设置40天过期时间，自动清理历史数据
