📐 模板管理（核心系统模块）

整个证书/记录体系的基石：证书模板 + 记录子模板 + 模板分类

1. 模板体系架构

层级实体说明前端页面
1 模板分类 ms_template_classify 3层树形结构：专业 → 科室 → 证书类型 views/basics/msTemplateClassify/index.vue
2 证书模板 ms_template_info Word格式证书模板，含书签占位符 views/template/msTemplateInfo/index.vue
3 记录子模板 ms_template_child Excel格式原始记录模板 在证书模板页面内联管理
💡 调用关系：模板分类ID (classify_id) ← 证书模板 (template_info) ← 记录子模板 (template_child)
一个证书模板可以有多个记录子模板（如不同的检测项目用不同的记录表）

2. 证书模板接口列表（约40个）

API：xiziyi-lims-web/src/api/template/msTemplateInfo.js

2.1 证书模板 CRUD

GET/measure/msTemplateInfo/list模板列表
GET/measure/msTemplateInfo/pageList无权限分页列表
POST/measure/msTemplateInfo新增模板
PUT/measure/msTemplateInfo修改模板
DELETE/measure/msTemplateInfo/{id}删除模板

2.2 模板操作流程

GET/measure/msTemplateInfo/submit模板提交
POST/measure/msTemplateInfo/audit证书模板审核
GET/measure/msTemplateInfo/templateStop暂挺/启用模板
GET/measure/msTemplateInfo/copy复制模板
GET/measure/msTemplateInfo/recordList操作历史
GET/measure/msTemplateInfo/dataInfo基础数据统计

2.3 PageOffice 在线编辑

GET/office/api/word打开Word编辑
GET/office/api/openWordTag获取书签
GET/office/api/openWordEchoTag书签回显
GET/office/api/excel打开Excel编辑
GET/office/api/recordEditExcel记录Excel区域只读模式

2.4 记录子模板 CRUD（属于证书模板的子表）

POST/measure/msTemplateChild新增子模板
PUT/measure/msTemplateChild修改子模板
DELETE/measure/msTemplateChild/{id}删除子模板
POST/measure/msTemplateChild/audit子模板审核
GET/measure/msTemplateChild/templateStop子模板暂停/启用
GET/measure/msTemplateChild/copy复制子模板

3. 模板 Word/Excel 文件管理（重点）

3.1 模板文件上传

// 文件上传接口 POST /common/upload → 通用文件上传 POST /common/uploadOriginal → 上传原始模板文件(.docx) POST /common/uploadOriginalSjImg → 上传送检原始模板图片 // 上传后返回文件路径，保存到数据库： ms_template_info.template_path → 证书模板路径 ms_template_child.template_path → 记录子模板路径

3.2 文件路径规则

文件类型路径模板
证书模板文件{profile}/template/{classify_id}/{template_id}/证书模板.docx
记录子模板文件{profile}/template/{classify_id}/{template_id}/child/{child_id}/记录模板.xlsx
上传的原始图片{profile}/upload/{date}/{filename}

3.3 核心数据表

表名关键字段
ms_template_infoid, classify_id(分类), template_name, template_code, template_path(模板文件路径), template_type(1证书/2记录), status(1待提交/2待审核/3已通过/4已驳回), create_time
ms_template_childid, template_id(父模板), child_name, template_path(子模板文件路径), item_id(检测项目), status
ms_template_classifyid, parent_id(父子关系), classify_name, classify_code(分类代码如JJG), level(层级1/2/3)

4. 模板审核流程

模板创建 → 提交(status=2待审核) → 审核员审核 ├── 通过(status=3) → 可用于业务 └── 驳回(status=4) → 退回修改 SQL: UPDATE ms_template_info SET status = #{status}, audit_user_id = #{auditUserId}, audit_time = sysdate() WHERE id = #{id}
⚠️ 模板开发常见问题：
  • 书签名称不匹配 → 检查模板 Word 中的书签名称与 Java 代码中的书签名称是否一致
  • Excel 区域只读 → 使用 office/api/recordEditExcel 接口设置 Excel 的部分区域只读
  • 模板路径在 Windows/Linux 不同 → 使用 FilePathUtil / PathConverter 处理路径
  • Aspose 水印问题 → 检查 license.xml 是否在 classpath 中且有锁
