2. Maven 模块依赖关系

xzy-admin (启动模块 + Controller层) ├─→ xzy-system (系统管理模块) │ └─→ xzy-common (通用工具模块) │ ├─→ xzy-measure (计量业务模块) │ ├─→ xzy-common │ └─→ xzy-basics (基础数据模块) │ └─→ xzy-common │ ├─→ xzy-quality (质量管理模块) ──→ xzy-common ├─→ xzy-crm (客户管理模块) ──→ xzy-common ├─→ xzy-basics (基础数据模块) ──→ xzy-common ├─→ xzy-quartz (定时任务模块) ──→ xzy-common ├─→ xzy-generator (代码生成器) ──→ xzy-common └─→ xzy-framework (框架核心) ──→ xzy-common

关键理解

💡 xzy-admin 是启动模块：包含 LimsApplication.java (启动类) 和所有 Controller。
💡 业务模块不含 Controller：xzy-measure、xzy-crm 等只含 Domain/Mapper/Service，Controller 统一在 xzy-admin。
💡 xzy-common 是基础层：BaseEntity、AjaxResult、工具类等通用内容。

5. 启动流程

1. 启动 MySQL (localhost:3306, db: lims) 2. 启动 Redis (localhost:6379) 3. cd xiziyi-lims-service/ 4. mvn clean package -DskipTests 或: mvn spring-boot:run -pl xzy-admin 5. 启动前端 (xiziyi-lims-web/) npm install && npm run dev 6. 访问: http://localhost:30001/xzy-api Swagger: http://localhost:30001/xzy-api/doc.html
