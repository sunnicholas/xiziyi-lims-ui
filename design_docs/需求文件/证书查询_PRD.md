# 西自仪 LIMS - 证书查询功能需求规格说明书 (PRD)

## 1. 需求概述
### 1.1 背景与目标
为了提升实验室管理效率及外部单位查询便捷性，需在系统中新增“证书查询”功能。该功能旨在通过多维度的筛选条件，帮助用户快速定位历史检定证书，并支持结果预览与数据导出。

### 1.2 目标用户
- **内部管理员/业务员**：进行日常业务对账、历史数据追溯。
- **检定/核验人员**：查看自己负责的证书记录。
- **外部委托单位**：通过特定权限或扫码查询本单位证书情况。

---

## 2. 业务流程与功能清单
### 2.1 核心功能清单 (MoSCoW)
- **Must (必须做)**:
  - [F01] 多维复合查询：支持 20+ 个关键字段的组合筛选。
  - [F02] 数据列表展示：结构化展示查询结果。
  - [F03] 证书在线预览：点击编号可直接查看证书 HTML/PDF。
  - [F04] 数据导出：支持将查询结果导出为 Excel。
- **Should (应该做)**:
  - [F05] 快捷检索：支持关键字模糊匹配（如器具名称、编号）。
  - [F06] 权限控制：不同角色仅能查询其权限范围内的证书。
  - [F07] 批量下载：勾选多条记录一键打包下载。
- **Could (可以做)**:
  - [F08] 客户扫码查询：支持外部委托单位通过二维码查询证书信息。
- **Won't (暂不做)**:
  - 证书在线修改与撤回（由业务受理模块负责）。

---

## 3. 详细需求定义
### 3.1 查询字段定义 (20+ 维度)
查询区域应采用“展开/收起”式布局，默认显示常用项，点击展开显示全部：

| 字段分类 | 字段名称 | 控件类型 | 说明 |
| :--- | :--- | :--- | :--- |
| **业务关联** | 业务员、受理人、证书单位 | 下拉/搜索 | 需关联系统用户表/单位表 |
| **日期时间** | 委托日期、检定日期 | 日期区间 | 支持开始-结束日期筛选 |
| **状态/类型** | 委托状态、签名状态、证书类型 | 下拉单选 | 状态流转需与系统一致 |
| **人员角色** | 检定员、核验员、批准人 | 下拉/搜索 | 需关联系统人员库 |
| **设备信息** | 计量器具名称、型号/规格、出厂编号、生产厂家、检定依据、检定结论、计量器具、检定地点 | 输入框/下拉 | 支持模糊匹配 |

### 3.2 列表展示字段 (表格)
结果页面表格应包含以下核心列：
1. **序号** (Index)
2. **证书编号** (带链接，可点击预览)
3. **计量器具名称**
4. **型号/规格**
5. **证书单位**
6. **委托日期 / 检定日期**
7. **检定员 / 核验员 / 批准人**
8. **量程** (新增隐性需求)
9. **仪器状态** (退检/已出证)
10. **操作** (预览、下载)

### 3.3 交互与展示规则
- **空值处理**：若查询无结果，显示“暂无数据”缺省图。
- **分页逻辑**：默认每页 20 条，支持翻页。
- **响应式适配**：PC 端表格展示，移动端采用卡片式列表展示。

---

## 4. 隐性需求补充 (系统稳健性)
- **数据安全**：外部查询需增加鉴权（如单位代码验证），防止数据泄露。
- **性能优化**：多字段组合查询需对数据库关键字段建立索引，查询响应时间控制在 2s 内。
- **异常处理**：
  - 网络超时提示：加载中动画 (Loading) 及失败重试按钮。
  - 导出失败提示：若数据量过大，采用异步导出。
