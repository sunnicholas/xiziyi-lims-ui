# 车辆管理系统设计方案

## 一、项目背景

### 1.1 现状分析
- 公司现有 10-20 辆车辆，包括汽油车、皮卡车、电动车等
- 车辆使用涉及限行问题：燃油车尾号限行、皮卡车区域限行
- 外检任务单需要配置车辆，但目前缺乏系统化管理
- 车辆保养、维修期间仍可能被错误调度

### 1.2 建设目标
- 建立完整的车辆档案管理体系
- 实现车辆状态实时监控与调度
- 自动处理限行规则，避免调度冲突
- 与现有 LIMS 系统无缝对接

#### 4.4.2 车辆选择过滤规则

```javascript
// 车辆可用性判断逻辑
function isVehicleAvailable(vehicle, taskDate, taskArea) {
  // 1. 检查车辆状态
  if (vehicle.status !== '可用') {
    return {
      available: false,
      reason: `车辆状态：${vehicle.status}`
    };
  }
  
  // 2. 检查限行规则
  const restriction = checkRestriction(vehicle, taskDate, taskArea);
  if (restriction.restricted) {
    return {
      available: false,
      reason: restriction.reason
    };
  }
  
  // 3. 检查保养计划
  const maintenance = checkMaintenancePlan(vehicle, taskDate);
  if (maintenance.hasPlan) {
    return {
      available: false,
      reason: `计划保养：${maintenance.planDate}`
    };
  }
  
  return { available: true };
}

// 限行检查
function checkRestriction(vehicle, taskDate, taskArea) {
  const rules = getRestrictionRules(vehicle.vehicleType);
  const dayOfWeek = new Date(taskDate).getDay();
  
  for (const rule of rules) {
    // 尾号限行检查
    if (rule.restrictionType === '尾号限行') {
      const lastDigit = vehicle.plateNumber.slice(-1);
      const restrictedDigits = rule.restrictedDays.split(',');
      if (restrictedDigits.includes(lastDigit)) {
        return {
          restricted: true,
          reason: `今日尾号 ${lastDigit} 限行`
        };
      }
    }
    
    // 区域限行检查
    if (rule.restrictionType === '区域限行') {
      const restrictedAreas = JSON.parse(rule.restrictedArea);
      if (isInRestrictedArea(taskArea, restrictedAreas)) {
        return {
          restricted: true,
          reason: `目标地址在限行区域内`
        };
      }
    }
  }
  
  return { restricted: false };
}
```
