# 智能体使用规划与规则书

## 1. 智能体概览

| 智能体名称 | 功能描述 | 适用场景 |
|-----------|---------|----------|
| **ui-designer** | 资深UI/UX设计师，将需求转化为设计方案 | UI设计、页面设计、界面设计、交互设计、设计规范、页面布局、设计方案 |
| **xiziyi-gas-process** | 气瓶业务流程UI设计总结 | 业务受理、样品管理、任务分配、记录录入等气瓶和安全阀业务流程 |
| **xiziyi-ui-refactor** | LIMS系统UI重构工具 | 优化现有页面结构、整合重复信息、添加在线/离线模式、改进上传功能 |
| **frontend-design-skill** | 前端设计技能文档 | 打造风格鲜明、可投入生产的高水准前端界面 |

## 2. 使用场景与触发条件

### 2.1 UI设计师 (ui-designer)

**触发条件**：
- 需要创建新页面或模块时
- 需要改进现有页面的UI/UX设计时
- 需要制定设计规范或设计系统时
- 需要创建用户流程图或信息架构时

**使用场景**：
- 项目启动阶段：制定整体设计方案
- 功能扩展阶段：设计新功能的UI界面
- 设计优化阶段：改进现有界面的用户体验

### 2.2 气瓶业务流程 (xiziyi-gas-process)

**触发条件**：
- 需要了解或改进气瓶和安全阀业务流程时
- 需要验证业务流程完整性时
- 需要参考现有业务流程设计时

**使用场景**：
- 业务流程规划阶段：参考现有流程设计
- 功能实现阶段：依据流程设计实现具体功能
- 系统验证阶段：检查业务流程覆盖完整性

### 2.3 UI重构工具 (xiziyi-ui-refactor)

**触发条件**：
- 需要优化现有页面结构时
- 需要整合重复信息时
- 需要添加在线/离线模式时
- 需要改进上传功能时

**使用场景**：
- 页面优化阶段：改进现有页面的结构和逻辑
- 功能完善阶段：添加新的模式或功能
- 性能优化阶段：减少重复代码和冗余信息

### 2.4 前端设计技能 (frontend-design-skill)

**触发条件**：
- 需要提升前端界面美观度时
- 需要制定前端设计规范时
- 需要优化前端代码质量时

**使用场景**：
- 界面美化阶段：提升现有页面的视觉效果
- 代码优化阶段：改进前端代码质量和性能
- 设计系统构建阶段：制定前端设计规范

## 3. 工作流程

### 3.1 新项目开发流程

```
需求分析 → ui-designer (设计方案) → 代码实现 → xiziyi-gas-process (流程验证) → 测试 → 部署
```

### 3.2 现有项目优化流程

```
问题识别 → xiziyi-ui-refactor (结构优化) → ui-designer (设计改进) → frontend-design-skill (界面美化) → 测试 → 部署
```

### 3.3 业务流程验证流程

```
流程设计 → xiziyi-gas-process (流程参考) → ui-designer (界面实现) → 功能测试 → 流程验证
```

## 4. 协作模式

### 4.1 智能体协作

| 场景 | 智能体组合 | 协作流程 |
|------|------------|----------|
| 新功能开发 | ui-designer + frontend-design-skill | 1. ui-designer 制定设计方案<br>2. frontend-design-skill 实现美观界面 |
| 业务流程优化 | xiziyi-gas-process + xiziyi-ui-refactor | 1. xiziyi-gas-process 参考流程设计<br>2. xiziyi-ui-refactor 优化现有实现 |
| 界面美化 | ui-designer + frontend-design-skill | 1. ui-designer 分析现有界面<br>2. frontend-design-skill 提升视觉效果 |
| 结构优化 | xiziyi-ui-refactor + ui-designer | 1. xiziyi-ui-refactor 重构页面结构<br>2. ui-designer 改进交互设计 |

### 4.2 与人类协作

1. **需求收集**：人类提供业务需求和功能要求
2. **智能体分析**：智能体分析需求并制定解决方案
3. **方案验证**：人类验证智能体提供的方案
4. **实施执行**：智能体根据验证结果执行具体任务
5. **结果审查**：人类审查执行结果并提供反馈
6. **迭代优化**：根据反馈进行迭代优化

## 5. 最佳实践

### 5.1 UI设计最佳实践

1. **需求明确**：在调用智能体前，明确说明需求背景、目标用户和功能要求
2. **参考资料**：提供相关参考资料或示例，帮助智能体更好理解需求
3. **迭代沟通**：通过多次交互迭代完善设计方案
4. **验证测试**：对智能体生成的设计方案进行验证测试
5. **持续优化**：根据用户反馈持续优化设计

### 5.2 代码实现最佳实践

1. **代码质量**：确保生成的代码符合生产环境标准
2. **性能优化**：关注页面加载速度和交互响应时间
3. **兼容性**：确保代码在主流浏览器中正常运行
4. **可维护性**：代码结构清晰，易于理解和维护
5. **文档完善**：为复杂功能提供必要的文档说明

### 5.3 业务流程最佳实践

1. **流程完整**：确保业务流程覆盖完整的用户场景
2. **逻辑清晰**：流程逻辑清晰，易于理解和执行
3. **状态管理**：完善的状态管理和错误处理
4. **用户体验**：流程设计符合用户操作习惯
5. **可扩展性**：流程设计具有良好的可扩展性

## 6. 案例示例

### 6.1 案例一：新增特种设备检测功能

**需求**：为系统添加特种设备检测功能，包括气瓶和安全阀的管理

**智能体使用**：
1. **ui-designer**：设计特种设备检测的整体界面布局和功能模块
2. **xiziyi-gas-process**：参考气瓶和安全阀的业务流程设计
3. **frontend-design-skill**：实现美观的前端界面
4. **xiziyi-ui-refactor**：优化页面结构和用户交互

**执行步骤**：
1. 调用 ui-designer 设计特种设备检测模块的界面布局
2. 参考 xiziyi-gas-process 的流程设计，确保业务逻辑完整
3. 使用 frontend-design-skill 实现美观的前端界面
4. 调用 xiziyi-ui-refactor 优化页面结构，添加在线/离线模式

### 6.2 案例二：优化现有样品管理页面

**需求**：优化现有样品管理页面，改进用户体验和功能完整性

**智能体使用**：
1. **xiziyi-ui-refactor**：分析并优化现有页面结构
2. **ui-designer**：改进页面的UI/UX设计
3. **frontend-design-skill**：提升页面的视觉效果

**执行步骤**：
1. 调用 xiziyi-ui-refactor 分析现有样品管理页面的结构问题
2. 优化页面结构，整合重复信息，改进上传功能
3. 调用 ui-designer 改进页面的交互设计和用户体验
4. 使用 frontend-design-skill 提升页面的视觉效果和美观度

## 7. 规则与约束

### 7.1 使用规则

1. **明确需求**：调用智能体前，确保需求描述清晰明确
2. **合理预期**：根据智能体的功能范围设定合理的预期
3. **迭代优化**：通过多次交互迭代完善解决方案
4. **验证测试**：对智能体提供的方案进行验证测试
5. **文档记录**：重要的设计决策和解决方案应记录在案

### 7.2 技术约束

1. **技术栈限制**：项目使用 Vue 2 + Element UI，智能体应在该技术栈内提供解决方案
2. **部署要求**：解决方案应符合 GitHub Pages 部署要求，无需构建过程
3. **性能要求**：页面加载速度快，交互响应及时
4. **兼容性要求**：确保在主流浏览器中正常运行

### 7.3 质量标准

1. **功能完整**：解决方案应覆盖所有核心功能需求
2. **用户友好**：界面设计应符合用户操作习惯，易于使用
3. **代码规范**：生成的代码应符合前端开发最佳实践
4. **文档完善**：重要功能和设计决策应有清晰的文档说明
5. **测试通过**：解决方案应通过基本的功能测试

## 8. 总结

本智能体使用规划旨在帮助项目团队充分利用现有的智能体资源，提高开发效率和设计质量。通过合理的智能体组合和协作模式，可以快速构建和优化符合业务需求的高质量前端界面，确保项目按时交付并满足用户期望。

在实际使用过程中，应根据具体需求和场景灵活选择智能体，并通过持续的反馈和迭代不断完善解决方案，最终实现项目的成功交付。
