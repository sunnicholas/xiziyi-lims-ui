🔗 三、一次请求的完整调用链路

以「用户查询委托列表」为例，展示请求从浏览器到数据库再返回的全路径

浏览器GET /xzy-api/measure/entrust/list
→
Nginx反向代理
→ localhost:30001
→
Filter 链XssFilter → RefererFilter
xzy-common/filter/
→
JWT Filter取Token→Redis查用户
xzy-framework/security/
→
ControllerMsEntrustTaskController
xzy-admin/measure/
→
ServiceMsEntrustTaskServiceImpl
xzy-measure/service/
→
MapperMsEntrustTaskMapper
xzy-measure/mapper/
→
MySQLlims库 → JSON返回
1客户端发送 GET /xzy-api/measure/entrust/list?pageNum=1&pageSize=10，Header 带 Authorization: Bearer <token>
│
2XssFilter：过滤请求参数中的 XSS 攻击字符
│
3JwtAuthenticationTokenFilter：从 Header 取 token → TokenService.getLoginUser() → Redis 查询 LoginUser → 校验有效期 → 写入 SecurityContext
│
4MsEntrustTaskController.list()：接收分页参数，调用 msEntrustTaskService.selectMsEntrustTaskList()
│
5MsEntrustTaskServiceImpl：通过 SecurityUtils.getUserId() 获取当前用户 → DataScopeAspect AOP 自动拼接部门数据权限 SQL → 分页查询
│
6MsEntrustTaskMapper + XML：执行 MyBatis-Plus 分页 SQL SELECT ... FROM ms_entrust_task WHERE ... LIMIT 0,10
│
7AjaxResult：Controller 将结果封装为 {"code":200, "rows":[...], "total":50} 返回浏览器

🔐 四、认证链路：登录 → JWT → 权限校验

1SysLoginController.login() — 接收用户名/密码/验证码
│
2SysLoginService.login() — 登录核心
│
3├─ loginPreCheck() → 空值校验 / 长度限制 / IP黑名单 (IpUtils.isMatchedIp())
│
4├─ validateCaptcha() → Redis 对比验证码，校验后删除
│
5├─ authenticationManager.authenticate() → Spring Security 认证
││
6│ └─ UserDetailsServiceImpl.loadUserByUsername() → 查DB用户 → 查角色权限 → 返回 LoginUser
│
7├─ recordLoginInfo() → 更新用户最后登录IP和时间
│
8└─ TokenService.createToken(loginUser) → UUID → JWT HS512签名 → Redis存储 → 返回 Token

关键安全文件

文件职责
SecurityConfig.javaCSRF禁用、无状态Session、JWT过滤器链、白名单URL（含微信/App接口）、BCrypt加密

DataScopeAspect.java@DataScope 注解AOP，自动拼接待办部门数据隔离SQL

│
6├─ msEntrustTaskMapper.insertMsEntrustTask() → 插入主表
│

│
8├─ [status=20] initSampleInfoData() → 自动生成样品台账信息
│
9├─ [条件] wxMessageAsyncService.sendTextMsgAsync() → 企微推送（开关控制）
│
10├─ [status=20] msTaskWarningInfoService.insertWarningInfo() → 创建超时预警
│
11└─ [status=20] publisher.publishEvent(EntrustProcessEvent) → 触发异步链路 ⤵

1TestTaskAllotController.add() — 批量任务分配请求
│
2TestTaskAllotServiceImpl.insertBatchTaskAllot() — 批量分配核心 (~1245行)

│
4├─ batchDeleteOldAllocations() → 删除旧分配记录

5.3 证书生成链路（审核通过后触发）

1审核通过 (status→50/60) — auditSubmit() 通过核验/批准

│
3BarcodeGenerator.generateQRCode() → 生成含防伪码URL的二维码 → ImageUtils保存PNG
│
4PdfCertCleanConverter → PDF → 600DPI渲染 → 裁剪空白 → 输出整齐证书图

│

⚡ 六、异步链路：事务提交后自动生成委托单

│
2EntrustProcessListener — @TransactionalEventListener(AFTER_COMMIT)
│
3├─ 注解保证：phase = AFTER_COMMIT → 数据库事务成功后才触发
││
4├─ 注解保证：@Async → 独立线程池执行，不阻塞HTTP响应返回
││
5└─ 调用 → entrustAsyncService.processEntrustData()

EntrustAsyncServiceImpl —— 异步文档生成核心 (~594行)

AcreateQuoted() → 选择模板引擎
│
B├─ 检验检测分类 → handleInspection()
││
C│ ├─ WordUtil.easyPoiExport() → EasyPoi 导出 Word 委托单
││
D│ └─ Word2PdfAsposeUtil.doc2pdf() → Aspose Word转PDF
│
E├─ 检定校准分类 → handleCalibration()
││
F│ ├─ JxlsExcelExporter.exportWithTemplate() → Jxls 导出 Excel
││
G│ ├─ ExcelToPdfUtil.convert*() → Excel转PDF
││
H│ └─ addWatermarksToPdf() → PdfImageWatermarkByKeyUtil 添加业务章+检验章
│
I├─ barcodeGenerator.generateCode128Barcode() → 生成Code128条形码
│
J└─ 更新DB → 委托单URL + 条形码路径保存
